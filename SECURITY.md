# Security Policy

## Scope

PulseBoard is a client-side demonstration project. It does not authenticate users, store server-side accounts, or connect to social media APIs. Its sample metrics are synthetic.

## Reporting a vulnerability

Please do not publish exploit details for an unresolved security issue. Contact the repository maintainer privately using the contact method listed on the GitHub profile. Include steps to reproduce, the affected file or feature, and the likely impact.

This repository does not currently operate a guaranteed response-time or bug-bounty program.

## Safe use

- Never add credentials, API keys, private analytics, or real personal information to commits or issues.
- Treat the optional local server as a development helper, not a hardened production server.
- Review and test changes before deploying them publicly.
